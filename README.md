## HTML Concepts Used

| Tag | Purpose |
|-----|---------|
| `<!DOCTYPE html>` | Declares the document as HTML5 |
| `<html>` | Root element of the page |
| `<head>` | Holds information about the page |
| `<title>` | Sets the title shown on the browser tab |
| `<body>` | Holds the visible content |
| `<h1>`, `<h2>` | Main heading and sub-headings |
| `<p>` | Paragraphs of text |
| `<hr>` | Horizontal line between sections |
| `<br>` | Line break |

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. To experiment, edit the headings, paragraphs and title, save the file and refresh the browser.
